# HIP-1402: Hanzo XP — Verified Contribution Protocol

## Abstract
This HIP defines the **Hanzo XP** protocol, a system for projecting developer mastery, agent capability, and scientific progress based on immutable evidence records.

## Protocol
- **Evidence-based**: XP is derived from verifiable experiments, fixes, and improvements. It is not an activity metric (e.g., tokens or PR count).
- **Specializations**: XP supports skill trees (Harness, Agent, Model, Science).
- **Qualification**: XP awards are reversible if results are retracted or found to be non-reproducible.
- **Audit**: XP acts as a progression ledger over existing infrastructure (HIP-1103 audit trail).
